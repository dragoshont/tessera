# All-in-One Delivery Contract

This repository adopts `TESSERA_ALL_IN_ONE_REAL_WORLD_DELIVERY_SPEC.md` as the delivery mandate.

The non-negotiable outcome is a continuously running homelab product with durable Chat, Memory, Actions, Jobs, real LiteLLM, Gmail OAuth/API access, and two independently authorized Regina Maria Accounts. External writes require exact one-use approval and provider re-read verification. No CAPTCHA/MFA bypass, fake connection state, mailbox-wide ingestion, cross-account session reuse, or unwanted live side effect is permitted.

Infrastructure remains plan-only under repository policy: a human reviews and applies/pushes the private homelab GitOps change. `DELIVERED_E2E` is forbidden until deployment and real external journeys pass.
